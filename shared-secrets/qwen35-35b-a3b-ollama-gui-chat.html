🔐 Secure Message Exchange

End-to-end encrypted messaging using RSA-4096 + AES-256-GCM hybrid encryption. Everything runs locally in your browser — nothing is sent anywhere.

🛡️ Client-Side Cryptography Only

🔑 Generate Key Pair

Generate a new RSA key pair. Your private key must be kept secret. Your public key can be shared with anyone who needs to send you encrypted messages.

How it works: We use RSA-OAEP with SHA-256 for key wrapping and AES-256-GCM for the actual message encryption. This hybrid approach gives you both strong security and the ability to send messages of any size.
⚠️ Warning: Store your private key securely. If you lose it, you will never be able to decrypt messages sent to you. If compromised, anyone can read your messages.
Algorithm
RSA-OAEP (SHA-256) + AES-256-GCM
Key Size
Key Format
PKCS#8 (private) / X.509 SubjectPublicKeyInfo (public), PEM-encoded

🔒 Encrypt a Message

Encrypt a message using the recipient's public key. Only the holder of the matching private key can decrypt it.

  1. Get the recipient's public key (shared via any channel)
  2. Paste their public key below
  3. Enter your message in the text area
  4. Click Encrypt — the output can be shared with anyone
Encrypted Payload (share this with the recipient)

🔓 Decrypt a Message

Decrypt a message using your private key. Paste the encrypted payload and your private key below.

  1. Get the encrypted payload (shared via any channel)
  2. Paste the encrypted payload below
  3. Paste your private key
  4. Click Decrypt — your original message will appear
Decrypted Message

All cryptography performed client-side using the Web Crypto API. No data ever leaves your browser.
